왜 이렇게 갈리나

설명
목록글의 유무카페엔 「강남역 카페 Top100」이 있고 조형물엔 없습니다. 목록글이 있으면 남이 나를 넣어주는 자리가 생기고, 없으면 내가 직접 쓰는 것 말고는 방법이 없습니다.
붐비면 무너지는 매체플랫폼의 「Top 100」은 AI가 위 몇 개만 골라 씁니다 → 붐비면 전환이 61% → 26% 로 떨어집니다. 블로그의 「카페 5곳」은 묶음째 가져갑니다 → 61% → 57% 로 거의 안 떨어집니다.
자사 채널이 먹히나조형물은 자사 글이 인용의 대부분입니다. 카페는 22곳 전부 0편 — AI가 카페 홈페이지를 근거로 쓰지 않습니다.
